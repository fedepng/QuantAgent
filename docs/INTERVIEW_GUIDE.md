# Interview Guide

## Why separate Agent and tools?

An LLM is useful for interpreting a request, but it should not invent market prices or calculate risk metrics token by token. QuantAgent limits the agent to planning and parameter routing. Market data, factor values, backtest series, and risk metrics are generated by deterministic tools with validated inputs.

## How is look-ahead bias prevented?

The factor matrix is shifted by one trading day before portfolio construction. A position earning the return on day `t` can only depend on information available no later than day `t-1`. The test suite changes the final day's close and verifies that every earlier equity value remains unchanged.

## How are transaction costs modeled?

At each rebalance, turnover is the sum of absolute changes in asset weights. Cost is turnover multiplied by the configured one-way basis-point rate. It is deducted from the same day's gross portfolio return. The test suite confirms that increasing cost cannot improve cumulative return.

## How is maximum drawdown calculated?

First build net value by cumulatively multiplying `1 + daily_return`. Then divide each value by the historical running maximum and subtract one. The minimum of that drawdown series is maximum drawdown.

## Why use FAISS with deterministic embeddings?

FAISS is responsible for vector indexing and top-k inner-product retrieval. The default embedding is a normalized multilingual hashing vector so the repository runs without downloading a model or requiring an API key. In production, a sentence-transformer or API embedding can replace the encoder while keeping chunk storage, index management, citations, and tests unchanged.

## Current limitations

- The built-in OHLCV data is deterministic simulation data, not exchange data.
- The default RAG encoder provides lexical/character similarity rather than deep semantic understanding.
- The backtester currently assumes close-to-close execution and one-way linear costs; it does not yet model suspensions, price limits, or market impact.
- The deterministic router is intentionally auditable. A production LLM planner would require schema-constrained output, retries, timeouts, and prompt-injection controls.
