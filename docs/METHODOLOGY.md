# QuantAgent 计算口径

## 因子

设收盘价为 `P_t`，窗口为 `N`：

- 动量：`P_t / P_(t-N) - 1`；
- 反转：`-(P_t / P_(t-N) - 1)`；
- 低波动原始值：最近 N 个日收益的样本标准差乘 `sqrt(252)`，排序分数取其相反数；
- 均线偏离：`P_t / SMA_N(P)_t - 1`；
- 成交量 Z-Score：`(V_t - mean_N(V)_t) / std_N(V)_t`。

快照先选择所请求区间内满足 80% 有效股票覆盖率的最后日期，再只用该日数据
排名。任一响应中的记录都属于同一个 `as_of_date`。

## 回测时序与会计

T 日收盘后得到信号，信号在下一研究日的 close-to-close 收益区间生效。请求的
`start_date` 是绩效统计起点；窗口预热可以读取起点以前的数据。首个可形成
Top-K 的持仓日开始调仓计数。

调仓目标为 Top-K 等权。两个调仓日之间，权重随资产收益漂移：

`w'_(i,t) = w_(i,t) * (1 + r_(i,t)) / (1 + sum(w_(j,t) * r_(j,t)))`

调仓换手为目标权重与漂移后权重的绝对差之和，净收益为：

`r_net = sum(w_i * r_i) - turnover * cost_bps / 10000`

初次从现金建仓的换手为 1 并收费；研究区间末尾不假设强制平仓。持仓资产在研究
日缺少 close-to-close 收益时受控失败，不把缺失收益填成 0。

## 风险指标

净值 `E_t = product(1 + r_i)`。回撤峰值序列显式包含初始净值 1.0，因此首日
亏损会立即形成回撤。日序列不额外伪造初始日期。

- 年化收益：`E_T^(252 / T) - 1`；
- 年化波动：日收益样本标准差乘 `sqrt(252)`；
- 夏普：日均收益除以日收益样本标准差，再乘 `sqrt(252)`，无风险利率按 0；
- 最大回撤：`min(E_t / max(1, E_1...E_t) - 1)`；
- Calmar：年化收益除以最大回撤绝对值；
- 日 VaR(95%)：日收益 5% 分位数；
- 日 CVaR(95%)：不大于 VaR 的日收益均值；
- 胜率：严格大于 0 的日收益占比；
- 平均日换手：有效回测日换手的算术平均。

空收益、非有限收益、单日跌幅不小于 100%、非正净值和非有限年化结果会返回
受控错误。单点或零波动序列的波动率和夏普按 0 返回。
