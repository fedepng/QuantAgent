# QuantAgent 当前能力与边界

本文描述 QuantAgent 2.0.2 的已交付事实，不是未来功能清单。详细计算口径见
[METHODOLOGY.md](METHODOLOGY.md)，本轮修正依据见
[CORRECTION_REQUIREMENTS.md](CORRECTION_REQUIREMENTS.md)。

## 已实现

- 本地单用户 FastAPI + 原生 Web 研究工作台；
- UTF-8/UTF-8 BOM 日线 OHLCV CSV 导入、结构化校验、原始文件和 Parquet 分离保存；
- 原始文件哈希、标准化数据哈希、相对存储路径、活动数据集完整性恢复；
- 动量、反转、低波动、均线偏离、成交量 Z-Score 五类因子；
- 固定覆盖阈值的同日横截面排名，返回截至日期、覆盖数、排除原因及因子方向；
- 使用滞后一日信号、漂移权重、Top-K 等权目标和线性交易成本的确定性回测；
- 收益、波动、夏普、回撤、Calmar、VaR、CVaR、胜率和换手率；
- 回测数据版本、Git commit、因子/风险/回测方法版本和完整日序列持久化；
- Responses 与 Chat Completions 两类 Function Calling 协议；
- 工具白名单、参数二次校验、调用耗时/状态/摘要/错误独立审计；
- 统一 API 错误对象与 request ID；损坏活动数据集的 degraded 健康状态；
- 页面历史回测恢复、动态行情快捷操作、重复提交保护和响应式图表。

## 有限实现

- 数据源仅为用户 CSV 和确定性模拟数据；系统不验证 CSV 是否来自交易所或其复权质量；
- 回测为日频 close-to-close 研究模型，初次建仓收费，期末不强制平仓；
- 持仓资产缺少收益时回测受控失败，未模拟停牌撮合、涨跌停、冲击成本和滑点；
- 因子排名采用 80% 最小覆盖率，适合研究演示但不等同于机构数据治理；
- Agent 最终文字具有模型不确定性，金融数值只来自确定性工具；
- SQLite 保存完整回测日序列，适合本地规模，不面向大规模并发。

## 未来候选（未实现）

- 外部行情 Provider、实时/分钟/Tick 数据；
- 命名股票池、增量导入、数据集删除和标准化数据导出；
- 基准指数对比、参数寻优、机器学习和自动因子挖掘；
- 报告导出、券商连接、模拟盘或实盘交易；
- 多用户、权限、云部署和团队协作。

## 验收边界

相同标准化数据、代码提交和参数必须得到相同数值结果。非法参数、未知股票、
区间无数据、预热不足、持仓缺价、文件损坏和模型不可用均必须返回稳定错误码，
不得以未处理异常或非有限 JSON 值结束。模拟数据和真实 CSV 均不构成投资建议。
